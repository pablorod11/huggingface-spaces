# QuantLab interface

Apple-inspired learning workspace. Preserve plain language, the actual three outcome probabilities, transparent made-up data labels and uncertainty. Brand remains QuantLab; no Apple marks, proprietary fonts or product assets are used.

## Visual system
Use the platform system font with optical sizing. Canvas #f5f5f7, opaque content #fff, ink #1d1d1f, secondary #626268, functional blue #0066cc. One thin sticky navigation layer may be translucent; reduced-transparency and higher-contrast preferences make it solid. Keep charts and results opaque. No decorative gradients, glass cards, stock imagery or external font dependencies.

Navigation names Price explorer, Number games, What if? and Help. Intro gives one short idea; primary price selector and action precede a centered result surface. The three exact percentages are the focal point. An additional chart representation is optional. Outcome color is emphasis, not an investment recommendation.

Use 16px surface radii, small rounded form fields, capsule action buttons and responsive whitespace. Desktop result figures scale up to 60px. Phone figures stack beside labels. Body text remains comfortable; captions remain readable and secondary colors meet contrast against their surfaces.

## Interaction
Settings are optional; file selection appears directly when needed. Hidden invalid fields reveal all ancestor disclosures before native validation focuses them. Navigation moves focus and scroll to the start of the selected view. Run focuses results after completion; cache hits stay labeled. Clear removes derived results and history. Native disclosures retain exact cutoffs, detailed validation, models and audits. Preserve export, file bounds, operation invalidation and chronological model behavior.

Use brief press feedback and a subtle view appearance only when reduced motion is not requested. Never delay input for animation. Respect reduced motion, reduced transparency and increased contrast.

## Reference study
Reviewed official Apple homepage, iPhone and iOS pages, MacBook Air presentation, Human Interface Guidelines for typography/layout/materials and the One Night on iPhone campaign. Applied hierarchy, purposeful spacing, product-first presentation and controlled disclosure. This is an adaptation for a web learning tool, not Apple certification or an exhaustive study of every product. See APPLE-REFERENCES.md for sources and review scope.


Training-support notes sit directly below the three probabilities in a restrained warm surface. Keep them plain and factual: few learning examples or unfamiliar recent patterns. They are not a formal confidence/drift claim. Hidden notes must be cleared when changing to an older saved report or clearing data. Never round a tiny nonzero chance into an apparent zero.

## Saved-guess checking
A native disclosure under result saving keeps the main three chances prominent. Plain labels, date/price controls, one explicit same-series confirmation and a short result precede optional technical scores. Practice results are labeled; file-timing and single-event limitations stay visible. Existing keyboard focus, typography and surface system are retained.

## Cost story
Number games gains a separate cost exercise with four primary inputs and optional cost settings. Percent inputs use plain percentage units throughout this exercise; exact basis-point conversion stays in the audit. Results explicitly describe gains/losses rather than an account balance. Native forms and disclosures preserve existing navigation and keyboard behavior. At390px the new form uses one column; mobile document width was measured without horizontal overflow.

## Cost comparison refinement
Added a plain cost-covering price-change sentence and an intermediate completed-before-costs result. Excess completed counts explain the correction and focus the relevant input. Editing inputs removes the old threshold and error styling so stale results are not mistaken for the new calculation.

## Investment explorer
A separate navigation view preserves the Price explorer and its original models. A white
settings surface sits beside the investment result on desktop and stacks on mobile.
USD value is the primary figure; ROI, gain/loss, drawdown or scenario outcomes follow.
Solid blue means mean/value, dashed purple means median, and the pale blue band spans
modeled 10th–90th outcomes. Source dates, conditional assumptions and historical/live
distinction stay visible. SVG charts support pointer inspection and a native range slider;
a bounded-height table provides the same values. Motion is a short opacity/position reveal
and is disabled by reduced-motion preference. No new runtime dependency is introduced.

## Forecast source and evaluation support
Price explorer adds a native ticker selector for dated public snapshots. Ticker, adjustment
and final-date context accompany results and survive exports. A compact table below the
probabilities separates historical outcome counts, average predicted chances and observed
rates. Sparse evaluation support is visible there with its heuristic limitation. Changing
inputs removes stale results; inactive controls are disabled. The forecasting policy was
retained after the single heavy-tail challenger failed its development gate.
