# Intake Desk

A browser-local customer inquiry demonstration for small businesses.

Capture inquiries, assign owners, search and filter requests, record next actions, close or reopen requests, and export the filtered view as CSV.

Use fictional information only. Records stay in the visitor’s browser; they are not shared with staff or synchronized to a server. No customer messages are sent. This demo has no staff authentication or server backups.

CSV generation passes logic tests; actual browser download verification remains pending. Best-effort stale-save checks do not provide atomic multiuser concurrency.
