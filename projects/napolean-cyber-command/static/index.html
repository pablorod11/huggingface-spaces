Local workspace recovery

  1. Export a workspace JSON backup before clearing browser data, changing browsers, or moving devices. Choose All clients for a complete backup.
  2. Export initiates a browser download. Confirm the file exists in an approved location yourself; this app cannot check that it was saved.
  3. In the destination browser, choose Restore backup, inspect clients and record counts, and confirm. Restore adds copies with new IDs and preserves existing records.
  4. Snapshot digests are checked before restore writes. A digest detects corruption; it does not authenticate identity or evidence.
  5. Keep customer records in approved browser profiles. Client labels organize records but provide no tenant isolation. Removing site data removes local records; this app has no server backup.

Approximate record size and optional browser-origin quota estimates are advisory. Browser storage policies vary. Metadata failures do not block assessments.
