# Provenance and final runtime

The user invoked Napolean and Napolean Security, then required no Docker and no-cost hosting. The current deployment is a public Hugging Face Static Space with dependency-free HTML/CSS/JavaScript. It runs no server, GPU, model provider or upstream scanner. The evidence lifecycle and mission templates are original implementation of the requested commander/scope/discovery/challenge/adjudication concepts.

Napolean Security references AgriciDaniel/claude-cybersecurity, tanviet12/vbsec, agamm/claude-code-owasp, ghostsecurity/skills, goplussecurity/agentguard, codexstar69/bug-hunter, kenryu42/cc-safety-net, anthropics/defending-code-reference-harness, trailofbits/skills and cloudflare/security-audit-skill. None of their executables, source files or rule sets are bundled or claimed to run. Their licenses do not automatically license this original application.

The original Python engine supplied the application's original role/scenario template data. Static code checks are newly implemented text patterns, not a claim that Python AST analysis was ported to the browser. No model was trained or invoked.

Earlier Flask/Gradio prototype code may remain as historical developer reference in this repository/source bundle; README selects index.html with sdk:static. Those Python files and requirements are not active runtime dependencies. They are not prerequisites to using the project.

The preferred local Crawl4AI documentation fetch failed because its browser could not start; official host web retrieval was used. Graphify was not run because the workspace started empty and source relationships were small enough to inspect directly.

The deployment was initially private; the current public Space was verified on 2026-11-03. The optional publishing helper still deliberately creates a new private Space and does not change the existing deployment. Public source and app access are separate from assessment records saved in each visitor’s browser.

Primary documentation consulted on 2026-10-31:
