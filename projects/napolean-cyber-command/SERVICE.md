# A business service built around a no-cost project

The first offering is an analyst-led, fixed-scope security review and tabletop exercise for a business with limited internal security capacity. This is a commercial hypothesis, not a validated market or pricing claim. The project software and static hosting need no paid compute or model API; professional analyst time and business operations are separate from the project's hosting cost.

## Pilot deliverables

| Perspective | Work | Deliverable |
| --- | --- | --- |
| Red | Plan authorized adversary hypotheses | Scope, prerequisites, stop conditions and evidence requests |
| Blue | Triage supplied alerts and response readiness | Corroboration checklist and proposed detection/response changes |
| White | Challenge nominated source concerns | Evidence-backed findings, rejected candidates and remediation notes |
| Black | Model attacker objectives using fictional/approved lab facts | Threat scenarios and defensive checkpoints |
| Purple | Connect hypotheses with observable control behavior | Joint exercise plan and coverage backlog |

The app supplies bounded heuristic candidates and original mission templates. Qualified analysts do the actual assessment and evidence review. It does not run five AI agents, execute attacks, monitor production or certify compliance.

## Engagement

1. Agree business priorities, assets/revision/time window, written authority, allowed activities, exclusions and incident contacts.
2. Use minimal approved snippets or normalized event batches. Keep raw source/logs in the customer's controlled system.
3. Run bounded local checks; challenge candidates and record evidence/mitigations before choosing a verdict.
4. Export a report and explain demonstrated impact separately from severity hypotheses and missing coverage.
5. Record remediation owner, due date, state and retest notes. Use role handoff notes to document the next evidence request. Agree commitments and residual risks with the customer.
6. Capture a frozen report version after analyst review (up to three per assessment), then deliver its print view or Markdown report through approved channels and save a workspace backup. Use the confirmed-only remediation queue to track owners, statuses and overdue dates in UTC. Manually discovered findings can be added as unresolved candidates and reviewed through the same evidence workflow. Test recovery with synthetic records before relying on it for an engagement.

Each browser/profile/origin has its own records. Teams do not automatically share cases, and there is no managed customer database. Share reports through the customer's approved channels. Validate retention, export handling, consent and data processing arrangements before accepting sensitive material.

Start with synthetic demos and a small set of scoped pilots. Measure analyst time, candidate validation outcomes, report usefulness, agreed remediation completion and repeat engagement interest. Validate willingness to pay before building subscription billing. Do not promise24/7 monitoring, response SLAs or security certification without staffing and independent evidence.

If shared SaaS demand is established, separately budget identity/SSO, tenant isolation, secure durable storage, backups, audit events, ingress/job isolation, observability and incident handling. The current no-cost project deliberately avoids claiming these capabilities.

## Running an engagement

Use each assigned hat workbook to record an owner, progress, evidence reference, expected outcome, observed result and review decision. Add the analyst-written executive summary, business impact and prioritized recommendations before delivery. Reports include the original evidence chain and mission guidance as well as current decisions. The client-wide remediation view groups confirmed findings across local assessments, including linked continuations; check scope and provenance before counting repeated findings as separate business risks.

Start a continuation before reaching activity, snapshot or size limits. It preserves current evidence and tracking in a linked fresh record; retain the source for historical evidence and frozen reports. Use the recovery guide with synthetic copies before customer work. A displayed export time confirms a download was initiated, not that the operator saved or safely retained the file.
